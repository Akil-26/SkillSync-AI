# SkillSync AI

**AI-powered candidate ranking pipeline** that intelligently scores and ranks job applicants against a job description using a blend of semantic similarity and structured feature analysis.

## Architecture

```
data/
  candidates.jsonl.gz       ← Input: compressed JSONL of candidate profiles
  job_description.docx      ← Input: job description document

src/
  config.py                 ← All paths, schema, weights, thresholds
  utils.py                  ← IO, logging, text normalization helpers
  embedding.py              ← Sentence-transformer encode/save/load/cosine
  features.py               ← Structured features: disqualifiers, honeypot,
                               production experience, behavioral composite
  reasoning.py              ← Template-based justification generation
  ranking_engine.py         ← Blend scores, apply gating, sort
  precompute.py             ← Stage 1: offline preprocessing (network OK)
  rank.py                   ← Stage 2: offline ranking (no network, timed)

artifacts/                  ← Generated by precompute.py
  models/                   ← Cached sentence-transformer model
  embeddings/               ← .npy embeddings + ID mappings
  features/                 ← Feature tables + parsed JD cache

outputs/
  predictions.json          ← Final ranked output
  predictions_full.json     ← Full audit output with all component scores
```

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Place your data

Put `candidates.jsonl.gz` and `job_description.docx` in the `data/` directory.

### 3. Run Stage 1 — Precompute (one-time, network allowed)

```bash
python -m src.precompute
```

This downloads the embedding model (first run only), generates embeddings for all candidates and the JD, and computes structured feature tables.

### 4. Run Stage 2 — Rank (offline, no network, 5-min limit)

```bash
python -m src.rank
```

Options:
- `--top-k 20` — Only output the top 20 candidates
- `--output path/to/output.json` — Custom output path

## Scoring Pipeline

Each candidate is scored via a weighted blend:

| Component | Weight | Description |
|---|---|---|
| Semantic Similarity | 40% | Cosine sim between resume & JD embeddings |
| Skill Match | 25% | Overlap of required vs. candidate skills |
| Production Experience | 20% | Log-scaled years + seniority + skill overlap |
| Behavioral Composite | 15% | Tenure stability & career growth trajectory |

### Gating (applied before/after blending)

1. **Disqualifiers** — Hard requirement failures (min experience, required skills, work auth) → score pinned to 0, excluded
2. **Honeypot Detection** — Suspicious profiles (keyword stuffing, fake emails, inflated resumes) → penalized or excluded
3. **Duplicate Detection** — Template-farm / bot-generated profiles flagged at batch level

### Justifications

Every candidate receives a **fully traceable, template-based justification** — no LLM hallucination. If a claim appears in the justification, it's because a feature computation produced that exact value.

## Constraints

- **CPU-only** — No GPU required
- **No network at inference** — Stage 2 runs fully offline
- **5-minute time limit** — Enforced wall-clock timeout
- **16 GB RAM cap** — Designed for commodity hardware
- **Embedding model**: `sentence-transformers/all-MiniLM-L6-v2` (384-dim)
